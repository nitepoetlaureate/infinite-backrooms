  Priority: P1 | Time: 2-3 hours | Dependencies: Task 1.2

  Current Issue: Thread-based workaround (run_async_in_thread) works but adds complexity

  Action Steps:
  1. Implement Streamlit singleton pattern for client management
  2. Replace thread pool approach with asyncio.run() where safe
  3. Keep thread fallback for edge cases with proper error handling
  4. Add comprehensive exception handling for event loop issues
  5. Test thoroughly with integration tests

  Implementation Approach:
  @st.experimental_singleton
  def get_ollama_client() -> OllamaClient:
      """Singleton Ollama client for app lifecycle."""
      return OllamaClient()

  # Use asyncio.run() with fallback
  def safe_async_call(coro):
      try:
          return asyncio.run(coro)
      except RuntimeError as e:
          if "Event loop is closed" in str(e):
              return run_async_in_thread(coro)
          raise
